# The site's fonts

Kept here so that building the site downloads nothing: `next/font/google` fetched them from Google
at build time, and a build failed whenever that did.

| File                                     | Font                     | From                                        |
| ---------------------------------------- | ------------------------ | ------------------------------------------- |
| `geist-latin-wght-normal.woff2`          | Geist, variable          | `@fontsource-variable/geist` 5.3.0          |
| `jetbrains-mono-latin-wght-normal.woff2` | JetBrains Mono, variable | `@fontsource-variable/jetbrains-mono` 5.3.0 |

Both are under the SIL Open Font License 1.1, unlike the rest of this repository: see
`geist-OFL.txt` and `jetbrains-mono-OFL.txt`.
