    Addresses
    
            
    
            
    
              The dashboard listens on this computer alone. From another, forward the port over SSH
              (ssh -L 28680:127.0.0.1:28680 this-computer), or turn the
              tunnel on.
            
    
          
    

          
    
            
    Tunnel
    
            
    
              A tunnel gives the dashboard an https:// address anyone can open, with
              its sign-in as the only lock. Tunnels are made with
              rustunnel, and with nothing else: its server carries, and can read, everything that passes. It
              needs the rustunnel client installed for this user, with its token set by
              rustunnel setup;
              rustunnel.com
              has the client and an account.
