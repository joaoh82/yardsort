Yardsort server

Sign this computer in as a host, so the devices you pair with it reach it. You sign in at the server in a browser, as yourself.

Open the sign-in page

Once signed in, the browser is sent to an address starting http://127.0.0.1/signed-in, which goes nowhere unless that port is forwarded to this computer. Copy the whole address from its address bar, and paste it here.

Pair a device

Let a phone, or the Yardsort app on another computer, reach this one. It asks with a code; you say what it may do. Nothing is let in without your answer.

Agents

    Addresses
    
            
    
            
    
              The dashboard listens on this computer alone. From another, forward the port over SSH
              (ssh -L 28680:127.0.0.1:28680 this-computer), or turn the
              tunnel on.
            
    
          
    

          
    
            
    Tunnel
    
            
    
              A tunnel gives the dashboard an https:// address anyone can open, with
              its sign-in as the only lock. Tunnels are made with
              rustunnel, and with nothing else: its server carries, and can read, everything that passes. It
              needs the rustunnel client installed for this user, with its token set by
              rustunnel setup;
              rustunnel.com
              has the client and an account.
