session.jsonl: the shape of a Claude Code 2.1.285 transcript (~/.claude/projects/<folder>/<session>.jsonl),
as far as usage goes. Field names and nesting are copied from a real transcript; the text, ids and paths
are made up. Message msg_B is written twice, once per content block, the way Claude Code writes it, the
second time with more output. msg_S is the <synthetic> message Claude Code writes without calling a model.
