OpenCode 2.2.6, recorded 2026-11-10 with scripts/record-opencode.sh.
One 'opencode run --standalone --auto' turn under a throwaway XDG_DATA_HOME, the capture plugin (a folder) given through OPENCODE_CONFIG_CONTENT's plugins, with a rule that every shell command asks first.
Each file is one plugin hook event or bus event ({api: 2, hook, payload, directory}); streamed text, reasoning and tool input, and catalogue events are left out.
Paths and ids are redacted; 01-init.json shows the inherited YARDSORT_* variables.
