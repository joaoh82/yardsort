## Ask first

Reading is always fine. Anything that starts an agent, makes a branch, runs something or writes,
say exactly what you will run, and why. Then run that one command. `ys` does not run it until
the user presses **Allow** in the Yardsort window. One yes covers that command, not what you
think of next. Do not try to answer the confirmation yourself, and do not ask the user to type
yes in this terminal: the yes is the button in the app. If `ys` says the command was not run,
stop. Anything that costs the user money or other people's attention is one of these: each agent
spends tokens, and a comment is seen by everyone on the repository.
