## Trusted

You may start agents, workspaces, workflows, smoke tests, schedules and checkouts, and other
writes that are not on the never list, without waiting. Say the exact command in a line as you
run it, so the user can see it. One command at a time. A further idea is a further command.
Anything that costs the user money or other people's attention still deserves that one line
before you run it: each agent spends tokens, and a comment is seen by everyone on the repository.
